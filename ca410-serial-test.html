② 選擇序列埠

CA-410 在 Windows 是某個 COM 編號，macOS 是 usbmodem 開頭。原廠 UI 必須先關掉，否則埠會被它佔住。

③ 開啟並測試

鮑率
這顆會依序送出官方通訊規格書 2.1 節的完整範例序列，每一步等機器回應才送下一步：
COM,1 → SCS,4,60.00 → FSC,1 → OPR,1 → MMS,0 → FMS,0 → MDS,0 → MCH,0 → LUS,1 → ZRC → MES,1 → COM,0
其中 ZRC 是零校正，做之前請把探頭的遮光蓋蓋上；量測 MES,1 時再打開對準畫面。
送出
結尾符號只能用 CR。規格書 1.2.1 節明訂指令必須以 CR 結尾，多送一個 LF 會被判為格式錯誤而回 ER10。
快捷
MES,1 之前一定要先做過 OPR,1（指定輸出探頭）和 ZRC（零校正），少了任何一步都會回 ER10。
