② 選擇序列埠

按下後會跳出系統的埠清單。CA-410 在 macOS 通常顯示為 usbmodem 開頭，在 Windows 是某個 COM 編號。原廠 UI 必須先關掉，否則埠會被它佔住。

③ 開啟並測試

鮑率
送出
結尾符號只能用 CR。官方通訊規格書 1.2.1 節明訂指令必須以 CR 結尾，多送一個 LF 會被判為格式錯誤而回 ER10（Command error）。
快捷
正常順序是先 COM,1（應回 OK00），再做其他事，最後 COM,0。MES,1 的回應長得像 OK00,P1,0,0.327…,0.419…,4.807…，依序是探頭、狀態、然後是量到的數值。
