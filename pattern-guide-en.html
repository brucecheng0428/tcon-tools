1About this tool

Use the browser to push a test pattern across the whole screen, one pixel to one pixel, no scaling. You can also build your own 4×4 sub-pixel unit and tile it edge to edge, or save the result as PNG or BMP for test equipment.

What it does

  • Test patterns — a full set of common patterns is built in (gray bars, Skip Dot, Line, Checker, Cross Talk, SMPTE…), with the same menu structure as the original program.
  • Manual 4×4 — set the gray level of 4 rows × 4 pixels × RGB, 48 sub-pixels in all, and tile them across the screen.
  • Mask — reveal only some segments of the screen and cover the rest (this is our addition; the original program has no such feature).
  • Save image — export PNG or BMP at the resolution you enter, in 8 or 10 bit. The pixels are verified automatically once the file is written.
  • Magnifier — zoom in on the spot to inspect the sub-pixel layout and the value of every cell.

Three things to know first

  • The preview on the main page is not 1:1 - it magnifies the pattern into a 3×3 tiling so you can see the structure clearly. For the real scale, go full-screen or use “1:1 actual pixels” in the output section.
  • The pattern shown at startup is Horizontal 256 (white / red / green / blue gray bars running left to right), not an empty manual mode.
  • Screen scaling will fool you - if the system is not at 100% scaling, CSS pixels and real device pixels do not match. The screen info card in chapter 11 tells you the current ratio directly.

2Quick start

Pick a test pattern

Press “▾ Test Pattern Menu” and choose from the menu (for example Skip 1 Dot ▸ 1V 1H). The preview above updates immediately.

Set the color and gray level

The color buttons 1–8 and the Level slider in the Pattern Parameters card. These two are what the number keys and the up/down keys do in the original program.

Push it to the whole screen

Press “⛶ Enter full-screen”. You can still change patterns and gray levels from the keyboard in full-screen. The control panel can sit on either side; press F or Esc to leave.

Inspect the sub-pixel layout

Wherever a pattern is shown, click the 🔍 badge in the top-right corner to open the magnifier. The arrow keys move the crosshair, and the area can be 3×3 / 5×5 / 9×9 / 13×13.

Save a file when you need one

Expand “Output and Save”, enter a resolution (or press “Use screen”), pick PNG or BMP and the bit depth, then press “💾 Save image”. After saving, the file is verified automatically to be pixel-identical to the pattern.

5The manual 4×4 editor

Available after you switch to “🎛️ Manual 4×4”. What you edit is a repeating unit of 4 rows × 4 pixels; each pixel has three sub-pixels, R, G and B, so there are 48 cells in all. In full-screen this unit is tiled 1:1 across the whole screen. → Open this card in the tool

How to use it

Tap a cellApplies the current gray level to that sub-pixel. So the order is: set the gray level first, then tap the cell.

Tap an L1–L4 headerSelects the whole row.

Once a third level appears, or the 48 cells have only one left, lit and dark no longer make sense, and these two buttons are disabled together with “Swap lit/dark”, with the reason shown.

The slider still moves when nothing is selected, but all it does is set the brush value used when you tap a cell; nothing on screen changes. To change everything at once, press Select all first.

6Full-screen display and keyboard control

This is where you actually look at the pattern. Once you enter, the pattern fills the whole screen at 1:1.

Control panel

  • The panel can be set to the left or right (“Control panel side in full-screen” on the main page, or “⇄ Switch panel side” on the panel itself).
  • The panel holds the test pattern menu, the side switch, the exit button, the keyboard help and details of the current pattern.
  • The left and right edges of the screen are hot zones: the panel only appears when the mouse moves there, so it never covers the pattern the rest of the time.
  • Right-clicking in full-screen also opens the test pattern menu.

Three ways to leave

  • Press F - an explicit exit from full-screen that also closes the magnifier.
  • Press Esc - it closes one layer at a time: the menu first, then the magnifier, then the 1:1 preview, and only then full-screen.
  • The “✕ Exit full-screen” button on the panel.

Saving, batch export and verification

ControlDescription
💾 Save imageBuilds the file from the current settings and downloads it.
📤 Share image with another appIt only appears when the device supports file sharing (usually a phone). Sharing and downloading use the same file; nothing is re-encoded for the sake of sharing. If you cancel the share, it does not force a download instead.
Export several sizes at onceTick several sizes and export them in one go. Every size is drawn natively at that resolution and verified separately - it is not one image scaled into several.

Why verify automatically The worst thing that can happen to a test pattern is a saved file that differs from what you saw - browser encoding, color management and scaling can all change pixel values quietly. Here every save is decoded back and compared for real, and anything other than 0 differences is flagged in red, so nobody has to check by eye.

When dPR is not 1, even “full-screen 1:1” is not really 1:1 The browser draws CSS pixels and the system then scales them up to physical pixels - interpolation is unavoidable, and the sub-pixel pattern is distorted. For pixel-level testing, set the system display scaling to 100% first, or use “Save image” and show the file on the test equipment instead.

12FAQ

Click a question to open the answer.

I move the gray level slider but nothing on screen changes?▼

Because nothing is selected right now. Gray level actions apply only to selected sub-pixels; with nothing selected, no cell moves (the slider merely sets the brush value). Select something first: tap a cell (tapping a cell applies the value directly), tap a header to select a whole row, a whole column or a whole color, press Select lit group / dark group, or press Select all to change everything. The right-hand side of the selection row states how many cells the value will reach.

The “Edit manually from here” button is grayed out?▼

It means this pattern is not a 4×4 periodic pattern - gray bars, SMPTE, Cross Talk and other pictures that differ everywhere have no repeating unit to copy into the 4×4 editor. The reason is written next to the button.

The preview looks different from the real display?▼

The preview on the main page is a magnified 3×3 tiling, meant to make the structure easy to see; it was never 1:1. For the real scale, enter “⛶ Enter full-screen”, or switch the output section to “1:1 actual pixels” or “⛶ Inspect 1:1 on the whole screen”.

The arrow keys do nothing in full-screen?▼

Two possibilities. Either the magnifier is open - the arrow keys then move its crosshair and the pattern arrow-key functions are paused entirely, so close the magnifier; or the focus is sitting in an input box, in which case click an empty part of the page and try again. Also, the arrow keys mean different things on different pattern types (see the table in chapter 6).

Does 10-bit output improve image quality?▼

No. The pattern itself is still generated at 8 bit; 10 bit only expands each channel by MSB replication when saving (0→0, 255→1023), for equipment that only accepts 10-bit images. It cannot invent intermediate levels that 8 bit could not reach.

The verification after saving shows red. What now?▼

Red means the pixels decoded back do not match the pattern exactly (the difference count is not 0, or the width and height are wrong). That file is not suitable for pixel-level testing. Try the other format (PNG ↔ BMP) and save again; if it still fails, report the message shown - it means the browser encoder is misbehaving.

I cannot see the “Share image” button on my phone?▼

The share button only appears when the browser really does support file sharing; where it is not supported it is hidden completely, so you never press it only to fail. Just use “💾 Save image” to download instead - the content is identical.
