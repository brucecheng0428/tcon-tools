為什麼需要一支 exe，不能全部做在網頁裡？
缺的不是「知道怎麼跟治具講話」—— 協定早就逆向清楚了，PQ Tool 就是這樣做的。 缺的是管道：那顆 FTDI 驅動只開放給原生程式直接呼叫 DLL，而瀏覽器裡的 JavaScript 沒有任何辦法呼叫本機 DLL，它只有 WebUSB／Web Serial／WebHID 三個 API。
WebUSB 也走不通，而且卡住的地方要分清楚：Windows 在裝置綁定層把 FTDI 的 interface 綁在 ftdibus.sys（D2XX）／ftser2k.sys（VCP）上， 而 claimInterface() 需要該 interface 掛的是 WinUSB 類驅動 —— 所以就算把所有程式都關掉，瀏覽器一樣拿不到。這不是「誰先佔用」的問題。 更換驅動這條路不做（Bruce 2026-09-17 裁示），所以在不換驅動、不換硬體的前提下， 本機跑一支橋接程式是唯一成立的路。
