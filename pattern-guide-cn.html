1工具简介

用浏览器把测试画面推到整个屏幕上，一个像素对一个像素、不缩放。也可以自己编一个 4×4 的 sub-pixel 图样平铺满版，或把结果存成 PNG／BMP 给机台用。

它能做什么

  • 测试画面 — 内置一整套常用画面（灰阶条、Skip Dot、Line、Checker、Cross Talk、SMPTE…），菜单结构与原程序一致。
  • 手动 4×4 — 自己指定 4 列 × 4 pixel × RGB 共 48 个 sub-pixel 的灰阶，全画面平铺。
  • 遮罩 — 只露出画面的某几等份，其余盖掉（这是本站加的，原程序没有）。
  • 另存图片 — 指定分辨率输出 PNG／BMP，可选 8 或 10 bit，存完自动验证像素是否完全一致。
  • 放大镜 — 就地放大看 sub-pixel 排列与每一格的数值。

三个要先知道的事

  • 首页的预览不是 1:1——它是把 pattern 放大成 3×3 平铺让你看清楚结构。要看真实比例请进全画面，或用输出区的「1:1 实际像素」。
  • 打开时的默认画面是 Horizontal 256（左到右的白／红／绿／蓝灰阶条），不是空白的手动模式。
  • 屏幕缩放会骗人——系统若不是 100% 缩放，CSS 像素与实际设备像素不一致。第 11 章的屏幕信息卡会直接告诉你目前的比例。

2快速开始

选一张测试画面

按「▾ Test Pattern Menu」，从菜单挑（例如 Skip 1 Dot ▸ 1V 1H）。上方预览立刻更新。

调颜色与灰阶

「画面参数」卡的颜色钮 1–8 与 Level 滑块。这两项就是原程序数字键与上下键在做的事。

推到整个屏幕

按「⛶ 进入全画面显示」。全画面中一样可以用键盘换画面、调灰阶；控制面板可切左右，按 F 或 Esc 离开。

看 sub-pixel 排列

任何有 pattern 的地方点右上角的 🔍，开放大镜；方向键移动准星，可切 3×3 / 5×5 / 9×9 / 13×13。

需要文件就另存

展开「输出与另存」，填分辨率（或按「用屏幕」）、选 PNG／BMP 与位深度，按「💾 另存图片」。存完会自动验证输出的像素与画面完全一致。

5手动 4×4 编辑区

切到「🎛️ 手动 4×4」后使用。编辑的是一个 4 列 × 4 pixel 的重复单元，每个 pixel 有 R／G／B 三个 sub-pixel，总共 48 格；全画面时这个单元会 1:1 平铺满整个屏幕。→ 直接打开工具的这张卡

操作方式

操作效果
点一个格子把目前的灰阶值套用到该 sub-pixel。所以顺序是：先设灰阶，再点格子。
按住拖拽连续涂刷多格。
点 L1–L4 标题选取整列。
点 px1–px4 标题选取整个 pixel 栏。
点 R／G／B 标题选取该颜色的所有 sub-pixel。
选取亮组／暗组按下的当下扫描 48 格的实际灰阶值：恰好只有两种时，较大的那个值是亮组、较小的是暗组（例如暗 L4／亮 L128）。每次改值都会重算。出现第三种亮度、或 48 格只剩一种时，亮暗之分不成立，这两颗与「亮暗反转」一起停用并显示原因。
亮暗反转两组的值互换。连按两次回到原状。

6全画面显示与键盘操作

真正要看画面的地方。进入后 pattern 以 1:1 填满整个屏幕。

控制面板

  • 面板可设定靠左或靠右（主页的「全画面时控制面板位置」，或面板上的「⇄ 切换面板左右」）。

控件说明
💾 另存图片依目前设定产生文件并下载。

11屏幕信息与缩放检测

只读信息，卡片默认收起。用来回答「我现在看到的到底是不是 1:1」。→ 直接打开工具的这张卡

字段意义
CSS 逻辑分辨率浏览器认知的屏幕尺寸。
devicePixelRatio每个 CSS 像素对应几个物理像素。不是 1 就代表有缩放。
推算设备像素CSS 分辨率 × dPR，也就是真正的面板像素数。输出区的「用屏幕」带入的就是它。
窗口内部尺寸／可用区域目前窗口与扣掉系统栏后的可用范围。

12常见问题

点问题展开答案。

我拉灰阶滑块，画面却没有任何变化？▼

因为当下没有选取任何格子。灰阶操作只作用在已选取的 sub-pixel 上，没有选取就一格都不动（未选取时滑块只是在设定笔刷值）。要改就先选：点那一格（点格子本身就是套用）、点标题选整列／整栏／整色，按选取亮组／暗组，或按全选改整片。选取行右侧会标明目前会套用到几格。

「以此为起点手动编辑」按钮是灰的？▼

代表这张画面不是 4×4 周期性图样——像灰阶条、SMPTE、Cross Talk 这种整张画面各处都不同的图，没有可以搬进 4×4 编辑格的重复单元。按钮旁边会直接写出原因。

预览看起来跟实际显示不一样？▼

首页的预览是放大后的 3×3 平铺，目的是让你看清楚图样结构，本来就不是 1:1。要看真实比例：进「⛶ 全画面显示」，或在输出区切到「1:1 实际像素」／「用整个屏幕 1:1 查看」。

全画面时方向键没作用？▼

两个可能：放大镜开着——此时方向键归放大镜移动准星使用，pattern 的方向键功能整个暂停，关掉放大镜即可；或是焦点停在某个输入框，点画面空白处再试。另外不同类型的画面，方向键的意义不同（见第 6 章对照表）。

选 10 bit 输出，画质会变好吗？▼

不会。画面本身仍是 8 bit 产生的，10 bit 只是存档时把每个通道用 MSB replication 放大（0→0、255→1023），供只接受 10-bit 图的机台使用。它不会凭空生出 8 bit 做不到的中间阶。

存档后的验证显示红色，怎么办？▼

红色代表重新解码回来的像素与画面不完全一致（差异数不是 0，或宽高不符）。这份文件不适合拿去做像素级测试。可以先改用另一种格式（PNG ↔ BMP）再存一次；若仍失败，请把显示的消息回报，那代表浏览器的编码行为有问题。

手机上看不到「分享图片」按钮？▼

分享钮只在浏览器确实支持文件分享时才显示，不支持就完全隐藏，避免按了才失败。此时直接用「💾 另存图片」下载即可，内容完全相同。
